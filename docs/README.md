# Auvra documentation

Auvra is a game engine and editor for building 3D games and shipping them as web or Windows builds.

- [Getting started](getting-started.md): run the editor, create a project and a level, and play it.
- [World Editor](world-editor.md): placing, transforming and organising objects, components, physics, lights, baked lighting, particles, audio, terrain painting, prefabs and shortcuts.
- [Assets](assets.md): importing models, textures and audio, import options, material overrides, material graphs, reimport and folders.
- [Level scripting](level-scripting.md): level blueprints, events, triggers, flow control, world nodes and level variables.
- [Gameplay scripting](scripting.md): Script components, the script editor, templates, the ctx API, limits and errors.
- [Multiplayer](multiplayer.md): playing together through a relay server, shared players, Network Sync objects, and network events in scripts and blueprints.
- [Timelines](timelines.md): keyed tracks that move, show and hide objects, write level variables and raise events; the timeline editor and playback settings.
- [Dialogue](dialogue.md): conversations with lines and choices, the dialogue editor, branching on level variables, dialogue events and translation.
- [Characters and animation](characters.md): player and enemy stats, enemy navigation, animation transitions, blend spaces, notifies, root motion, one-shot animations, IK and the graph preview.
- [HUD, menus and localization](hud-and-menus.md): the game HUD, title and pause menus, live values and translated text.
- [Building and shipping games](building-games.md): game settings, web and Windows builds, saves, player options, controls and the performance overlay.

Auvra is pre-alpha. Keep backups of important projects.
